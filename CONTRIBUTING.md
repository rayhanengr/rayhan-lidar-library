# Contributing to RAYHAN LiDAR LIBRARY

Thank you for your interest in contributing!

We welcome developers, engineers, and LiDAR
enthusiasts to contribute to this project.

## Contribution Guidelines

1. Follow the existing C# coding conventions.
2. Keep the core API vendor-independent.
3. Implement each LiDAR manufacturer through
   a separate driver.
4. Include tests and documentation.
5. Do not submit unauthorized proprietary code.

## Pull Requests

- Create a separate feature branch.
- Write clear commit messages.
- Explain your changes in the pull request.
- Ensure existing functionality is not broken.
